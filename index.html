📋 メニュー抽出スクリプト

🪜 使い方
  1. 下の「コピー」ボタンを押す
  2. 公式の各レストランページを開く
  3. F12 →「コンソール」→ 貼り付けて Enter
  4. JSONダウンロード → アプリで「JSONインポート」
🪜 使い方
  1. 下の「コピー」ボタンを押す
  2. 公式サイトの任意のページを開く（TDL/TDSどちらか）
    TDL →   TDS →
  3. F12 →「コンソール」→ 貼り付けて Enter
  4. 全店舗を自動取得（約20秒）後 JSON ダウンロード
  5. アプリで「JSONインポート」

🔖 ブックマークレット設定

① URLをコピーする
② ブックマークに登録する
Chrome の場合：
ブックマークバーを右クリック →「ページを追加」
名前：ディズニーメニュー取得
URL：①でコピーしたものを貼り付け → 保存
📱 設定後の使い方
  1. ディズニー公式のレストランページを開く
  2. ブックマークの「ディズニーメニュー取得」をクリック
  3. 画面にポップアップが出るので「アプリで取り込む」をタップ ✅
